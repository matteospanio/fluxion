geometry stages (change frames / rate / channels):
  trim — keep a [start, start+len) window (or [start, end)); drops the rest
      --start        <s>   default 0
      --len          <s>   default: to end
      --end          <s>   alternative to --len
  pad — prepend/append silence
      --start        <s>   default 0
      --end          <s>   default 0
  rate — resample to a new sample rate (windowed-sinc SRC)
      --fs           <Hz>   required
  speed — change speed (pitch+tempo together); keeps fs
      --factor       <lin>   required; >1 faster
  stretch — change tempo, not pitch; keeps fs
      --factor       <lin>   required; >1 faster
  repeat — concatenate the signal with itself count times
      --count        <int>   required
  silence — trim leading/trailing near-silence
      --threshold-db <dB>   default -60
      --min          <s>   guard band, default 0
      --leading      (flag)   trim the front
      --trailing     (flag)   trim the tail
  channels — up/down-mix to count channels (energy-preserving)
      --count        <int>   required
  remix — rebuild channels from a 1-based map, e.g. "1,2" or "1-2,3"
      --map          <spec>   required
